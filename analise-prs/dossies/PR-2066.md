## 1. Intenção

Duas correções:
1. **Produção** (`useAudioMemes.ts`): corrige o caminho de upload no bucket `audio-memes` — muda `meme_${Date.now()}_${uuid}.${ext}` para `${user.id}/meme_${Date.now()}_${uuid}.${ext}`. A política RLS do bucket exige `(storage.foldername(name))[1] = auth.uid()`, então qualquer upload sem prefixo do usuário falhava com `42501 (insufficient_privilege)` para não-admins.
2. **Teste** (`useAudioMemes.pasta-usuario.test.tsx`): adiciona mock Realtime (`channel: () => realtimeChannel`, `removeChannel: () => {}`) necessário para o hook não quebrar ao inicializar subscription.
