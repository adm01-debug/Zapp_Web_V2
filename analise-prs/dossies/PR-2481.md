## 2. Traz regressão?

**NÃO** — desde que o `WITH CHECK` seja idêntico ao `USING`. O patch adiciona `WITH CHECK (USING_expression)` igual ao USING existente. Comportamento atual (sem WITH CHECK) = Postgres usa implicitamente USING como WITH CHECK para UPDATEs, portanto adicionar explicitamente o mesmo valor é idempotente em produção e fecha o gap de segurança se o USING já estava correto.

Sem evidência de que alguma linha atual escapa do USING — gap fechado, zero regressão esperada.
