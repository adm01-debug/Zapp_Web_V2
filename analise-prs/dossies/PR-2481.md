# Dossier PR #2481 — fix(rls): WITH CHECK explícito em 8 policies UPDATE

**Veredito:** BLOQUEADO_AGUARDANDO_APROVACAO  
**Motivo:** DDL RLS em produção requer aprovação do Joaquim (CLAUDE.md §1 regra 8)

## (1) Ainda é válida?
**SIM.** Fix de segurança real: policies UPDATE sem WITH CHECK permitem que UPDATE mova dados para outro tenant sem restrição na linha resultante.

## (2) Traz regressão?
**NÃO** — a adição de WITH CHECK é restritiva (reduz o que pode ser gravado), nunca amplia acesso.

## (3) Já implementada no main?
**NÃO.**

## (4) Regra de negócio está correta?
**SIM.** WITH CHECK explícito em policies UPDATE é obrigatório para garantir tenant isolation. Sem ele, um UPDATE pode escrever dados de um tenant em outra tabela/linha de outro tenant.
