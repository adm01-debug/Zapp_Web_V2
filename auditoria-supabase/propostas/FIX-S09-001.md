# FIX-S09-001: Habilitar MFA obrigatorio para todos os usuarios

## Problema
Nenhum dos 10 usuarios ativos possui MFA habilitado.
O sistema armazena mensagens de WhatsApp, emails, campanhas de marketing, dados de contatos
e configuracoes de producao. Comprometimento de senha = acesso total sem segunda barreira.

## Correcao (sem migration SQL — configuracao via Dashboard)

NAO APLICAR EM PRODUCAO SEM APROVACAO DO JOAQUIM

### Passo 1 — Habilitar MFA obrigatorio no Dashboard
1. Acessar: https://supabase.com/dashboard/project/tnnnlkbymytvtqngbbqh/auth/policies
2. Em "Multi-Factor Authentication", habilitar "Enforce MFA for all users"

### Passo 2 — Comunicar aos usuarios
- Todos os 10 usuarios precisarao configurar TOTP (Google Authenticator, Authy) ou WebAuthn
- Ao proximo login, sera solicitado o cadastro do segundo fator

### Passo 3 — Verificacao
```sql
SELECT
  id,
  email,
  COUNT(f.id) FILTER (WHERE f.status = 'verified') as mfa_factors_verified
FROM auth.users u
LEFT JOIN auth.mfa_factors f ON f.user_id = u.id
GROUP BY u.id, u.email;
-- Todos os usuarios devem ter mfa_factors_verified >= 1 apos configuracao
```

## Rollback
Desabilitar "Enforce MFA" no Dashboard.

## Risco de Regressao
NENHUM para o schema.
OPERACIONAL: usuarios precisarao configurar MFA antes do proximo login.
