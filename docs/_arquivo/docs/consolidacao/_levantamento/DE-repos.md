## Regra de segurança da triagem

Arquivos cujo caminho sugere `.env`, credencial, token, key, secret, senha ou chave privada são **DESCARTAR da integração V2** até revisão individual. A regra conservadora também cobre arquivos de código e testes com esses termos no nome; o rótulo não afirma que contenham valores secretos. **NÃO copiar, colar, importar, commitar nem publicar valores** desses arquivos. O rótulo não autoriza apagar origens. Os hashes desses itens foram omitidos dos índices.

Todo `TERMINAR` baseado em diferença de árvore significa **verificar**, sem presumir que haja código aproveitável.
