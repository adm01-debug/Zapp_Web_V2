## Definição operacional dos buckets

- **ENTRA** — o PR tem conteúdo que a main NÃO tem e que ainda vale ⇒ vira lote de salvamento (portar).
- **JA-TEM-EQUIVALENTE** — a main já entrega o mesmo efeito (igual ou melhor) ⇒ não portar.
- **DESCARTA** — o conteúdo do PR não pode ser portado: artefato de ferramenta, ou conteúdo que
  quebra a main.

## Métrica (como "equivalente" foi medido, arquivo por arquivo)

   `ausentes = 0` ⇒ **a main é superconjunto do PR naquele arquivo**: nada a salvar.

#!/usr/bin/env python3
"""Prova de que a guarda scripts/ci/workflow-contracts.unit.mjs de uma revisao
e quebrada contra o proprio .github/workflows/ci.yml dessa revisao.

Uso: python3 verifica-e69.py <PR|BASE|MAIN> [sha]
Confere as listas `for (const job of [...])` da guarda contra os jobs do ci.yml.
Exit 1 quando a guarda exige job que nao existe no workflow.
"""
import re
import subprocess
import sys

REVS = {
    "BASE": "5721e4f5000c242bc7cfa984a7ffa44bf27768e5",
    "PR": "f3bbbaf08a",
    "MAIN": "a9b4d6c6fb",
}
GUARDA = "scripts/ci/workflow-contracts.unit.mjs"
CI = ".github/workflows/ci.yml"


def g(*a):
    return subprocess.run(["git", *a], capture_output=True, text=True).stdout


rotulo = sys.argv[1] if len(sys.argv) > 1 else "MAIN"
rev = sys.argv[2] if len(sys.argv) > 2 else REVS[rotulo]

ci = g("show", f"{rev}:{CI}")
jobs = set(re.findall(r"^  ([a-z0-9-]+):", ci, re.M))
guard = g("show", f"{rev}:{GUARDA}")
exigidos = set()
for lista in re.findall(r"for \(const job of \[([^\]]+)\]", guard):
    exigidos |= set(re.findall(r"'([a-z0-9-]+)'", lista))
for alvo in re.findall(r"anc\.has\('([a-z0-9-]+)'\)", guard):
    exigidos.add(alvo)

print(f"rev={rev}")
print(f"jobs_no_ci={sorted(jobs)}")
print(f"guard_exige={sorted(exigidos)}")
faltando = sorted(j for j in exigidos if j not in jobs)
if faltando:
    print(f"QUEBRADA: a guarda exige {faltando}, job(s) ausente(s) do ci.yml")
    sys.exit(1)
print("OK: a guarda casa com o ci.yml")
