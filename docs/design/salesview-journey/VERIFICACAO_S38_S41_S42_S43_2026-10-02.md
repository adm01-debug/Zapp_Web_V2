## Dois bugs de produção encontrados (registrados aqui)

### 1. A aba Journey não carrega em produção

```
Erro em "Journey"  Failed to fetch dynamically imported module:
  https://zapp-web-v2.vercel.app/assets/JourneyTab-B1r1ugA1.js
curl → JourneyTab-B1r1ugA1.js -> 404
```

O chunk dinâmico que a aplicação pede **não existe no deploy**. É a origem dos 404 observados no
console. **A aba Journey está inutilizável em produção.** Hipótese a verificar em etapa própria: mapa
de chunks defasado (build/deploy inconsistente ou cache de borda servindo um `index.html` antigo).

### 2. O banner de conexão do WhatsApp intercepta os cliques da barra de abas

```
[aria-label="Status das conexões do WhatsApp"] · altura 44px · top 0 · z-index 90
texto: "⚠️ Conexão "PRINCIPAL" está desconectada! Mensagens não serão enviadas/recebidas."
barra de abas: top 0 · altura 53px · bannerBottom 44 → cobertas: TRUE
```

**44 dos 53 px da barra de abas ficam sob o banner** (83%). Com o WhatsApp desconectado, **SalesView e
Journey não podem ser clicadas** — o Playwright registrou `subtree intercepts pointer events` em 19
tentativas seguidas. O banner tem botão próprio que o dispensa, mas nada indica isso ao usuário e ele
volta no reload. É a mesma classe do overlay `z-[9999]` corrigido hoje.
