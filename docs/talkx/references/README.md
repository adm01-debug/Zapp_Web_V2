# Referências visuais — Campanhas / Talk X

**Estado:** ativas, imutáveis e aprovadas como referência de composição. A implementação deve preservar o tema carvão; o azul destas imagens é referência de acento e hierarquia, não autorização para substituir o tema global.

Use [INDEX.html](INDEX.html) para navegar e [MANIFESTO.json](MANIFESTO.json) para conferir bytes, dimensões e SHA-256. O estado de execução está no [plano de recuperação](../PLANO_RECUPERACAO_100_ETAPAS_2026-09-11.md#estado-de-execução-em-12092026).

## Conteúdo

17 imagens PNG originais, nomeadas e numeradas por tela.

## Como usar

1. Extraia todo o ZIP para uma pasta.
2. Abra INDEX.html para navegar pelas imagens.
3. Clique em uma prévia para abrir o PNG original.

## Resolução

Todos os PNGs deste pacote têm 1672 × 941 pixels.
Os arquivos foram copiados sem cortes, conversão ou redimensionamento.
A resolução original de geração não é 1920 × 1080.

## Escopo

Inclui a tela principal aprovada e as duas séries posteriores de subtelas,
estados e modais. Não inclui os primeiros mockups rejeitados, screenshots
do sistema anterior nem imagens de outros módulos.
A prancha 17 reúne estados e modais em uma imagem; eles não são arquivos
individuais neste pacote. Não foram geradas telas novas nesta entrega.

Estas imagens são referências visuais, não uma implementação funcional.
Números, indicadores, textos e capacidades ilustradas não comprovam
funcionalidade existente nem substituem a validação técnica dos requisitos.
