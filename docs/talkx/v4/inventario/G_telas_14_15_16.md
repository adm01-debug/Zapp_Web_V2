- **Permissão:** RPC é INVOKER → respeita "Users can view own campaigns"; admin/supervisor vê todas. Nenhum componente Talk X checa papel (`grep -n "isSupervisor\|useUserRole" src/components/talkx` → vazio). Edge `talkx-report` só aceita o dono (`index.ts:60-71`).
- **Estado vazio/parcial:** 0 campanhas em produção — nada foi exercitado. Mock pressupõe links, conversões, segmentos e investimento; cada bloco precisa de regra "sem fonte → não renderiza" (regra 2 do V3). Não existe.
- **Campanha cancelada:** mock só desenha "Concluída"; relatório de `cancelled` (pendentes nunca enviados) não tem tratamento.
- **Loading/erro:** Monitor tem skeleton (`:99`) mas não trata erro da query nem id inexistente (`TalkXErrorState` existe em `talkxShared.tsx:449`, não usado aqui).
- **Realtime:** Monitor refaz fetch a cada 4s e assina realtime mesmo em campanha concluída (`:29,49,65,68-74`) — desnecessário num relatório.
- **Limites de leitura:** Monitor/Running leem 100–200 destinatários; mock tem 12.480 → abas Mensagens/Respostas/Audiência exigem paginação no servidor.
