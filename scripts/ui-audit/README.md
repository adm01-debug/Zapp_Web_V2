# scripts/ui-audit

Guards de auditoria da interface:

- `layout-guard.mjs` / `.unit.mjs` — verifica containers de tela com classe correta
- `width-check.mjs`, `width-regression.mjs` — detecta largura fixa fora do padrão
- `root-className.mjs` — verifica className do elemento raiz
- `contacts-navy-header.unit.mjs` — guard do header de contatos
- `view-container-padding.unit.mjs` — guard de padding de view containers
