# scripts/catalog

`validate-plan.mjs` — valida a estrutura do plano de implementação
(`docs/catalogo/PLANO_IMPLEMENTACAO_CATALOGO_100.md`): verifica Objetivo, 10 sub-etapas e
checklist por etapa; aceita tombstones `RISCADO` sem estrutura executável.

Uso: `node scripts/catalog/validate-plan.mjs [<caminho-do-plano.md>]`
